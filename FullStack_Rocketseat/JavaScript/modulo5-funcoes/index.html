Funções

O que são funções?

Funções são blocos de código reutilizáveis que realizam tarefas específicas.

Ela é definida uma vez e pode ser chamada (ou invocada) várias vezes ao longo do programa.

Funções ajudam a organizar o código e torná-lo mais legível, mantível e reutilizável.

Tipos de Funções

Existem três principais tipos de funções em JavaScript:

  • Função Declarada: Definida usando a palavra-chave function.
  • Função Anônima: Função sem nome, geralmente atribuída a uma variável.
  • Função Arrow: Sintaxe mais curta para funções anônimas, introduzida no ES6.
