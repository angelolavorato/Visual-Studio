Callback Function

Uma callback function é uma função que é passada como argumento para outra função e é executada após a conclusão de uma operação assíncrona.

As callbacks são usadas para lidar com operações que levam tempo, como requisições de rede, leitura de arquivos ou temporizadores.

Por exemplo, imagine que você quer buscar dados de um servidor. Você pode usar uma função de callback para processar os dados assim que eles forem recebidos, sem bloquear o restante do código. 

function fetchData(callback) {
        setTimeout(() => {
          const data = { message: 'Dados recebidos!' };
          callback(data);
        }, 1000);
      }

Neste exemplo, a função fetchData simula uma operação assíncrona usando setTimeout. Após 1 segundo, ela chama a função de callback, passando os dados como argumento.

Você pode usar essa função assim: 

fetchData((data) => {
  console.log(data.message);
});
Aqui, a função de callback é definida como uma função anônima que recebe os dados e imprime a mensagem no console.

Resumindo:

  • Uma callback function é uma função passada como argumento para outra função.
  • Ela é executada após a conclusão de uma operação assíncrona.
  • As callbacks ajudam a lidar com operações que levam tempo sem bloquear o restante do código.
