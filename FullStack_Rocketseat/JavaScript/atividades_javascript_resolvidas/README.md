# Atividades JavaScript Resolvidas

Este pacote contém 8 exercícios resolvidos de HTML, CSS e JavaScript.

Cada exercício está organizado no seguinte padrão:

```text
exercicio-XX/
├── index.html
├── css/
│   └── style.css
└── js/
    └── script.js
```

Conteúdos praticados:
- Estruturação HTML
- Estilização CSS
- Variáveis
- Tipos de dados
- Conversão de tipos
- Operadores
- Condicionais
- Funções
- Eventos
- Manipulação básica do DOM
- Organização de arquivos
